# dsh-quota-ring · DSH 余额环

在 DSH 侧边栏**左下角、账户名右边**，显示 **余额**、**今日花费** 和 **峰谷计价圆环**。

> ⚠️ **仅支持 macOS** —— 重启功能依赖 `launchctl` 与 `/Applications` 路径。
>
> ✅ **无需安装 Node，无需 `npm install`** —— 插件跑在 DSH 内部，而 DSH 是 Electron 应用，自带 Node 运行时。整个插件零第三方依赖。

![整体界面](docs/01-overview.png)

<sub>**先看它在哪** —— 左下角，账户名「余温叙良」的右边：`余:¥9.65` `今:¥1.92`。它和账户名**同一行**，不额外占用侧边栏高度。</sub>

---

## 它解决什么问题

想知道账户还剩多少钱，平时要：打开网页 → 登录 → 进用量页 → 看一眼 → 关掉。

一天要看七八次。

这个插件把三个信息钉在你眼前，扫一眼就知道：

| 你看到的 | 含义 |
|---|---|
| `余:¥9.65` | 账户**当前余额**（平台接口返回的真实值） |
| `今:¥1.92` | **今天已经花了多少**（扫描本地会话日志 + 内置价目表估算） |
| **圆环** | 今天花费的**构成**，以及此刻是**高峰还是闲时** |

## 二、数字会"翻"一下，还会变色

数字不是直接跳变的 —— 每次更新都会**翻动 + 变色**，让你一眼注意到"钱变了"。

![今日花费上涨变黄](docs/04-roll-yellow.png)

<sub>今日花费从 ¥1.71 涨到 **¥1.73** —— 「今:¥1.73」整串变成**黄色**，表示刚刚又花了一笔。</sub>

![余额下降变粉](docs/05-roll-pink.png)

<sub>余额从 ¥9.86 降到 **¥9.83** —— 「余:¥9.83」整串变成**粉色**，表示钱在减少。</sub>

### 翻转是怎么动的

1. **每个字符独立** —— 包括 `¥` 和小数点，都是一个一个的字
2. 变化时从**下方 7px** 浮上来，同时从**半透明**变成实心
3. 持续 **0.45 秒**
4. 每个字符**依次延迟 18 毫秒** —— 所以是从左到右**一波推过去**，像老式翻牌器

### 变色代表什么

| 数值变化 | 颜色 | 含义 |
|---|---|---|
| **余额增加** | 灰绿 `#96C6A9` | 充值到账，钱变多了 |
| **余额减少** | 粉红 `#ff8fa3` | 钱在流出 |
| **今日花费增加** | **黄色 `#ffb020`** | 又来一笔消耗 |
| **今日花费减少** | 粉红 `#ff8fa3` | 罕见（通常是跨天归零） |

颜色只停留 **1.7 秒**，然后自动恢复默认色 —— 看得见变化，又不会一直花花绿绿。

### 为什么"今日花费上涨"用黄色，不用绿色

因为「今日花费」是**支出**。

如果花钱也闪绿色，会让人下意识觉得"情况变好了" —— 实际是钱在流出去。

所以这里用黄色（警示色），和「余额减少」的粉色明确区分：

- **余额涨** = 绿 → 好事
- **余额跌** = 粉 → 钱少了
- **今日花费涨** = 黄 → 在花钱

## 三、圆环：点它就是重启 DeepSeek

![悬停圆环](docs/06-hover-ring.png)

<sub>**点击圆环是重启 DeepSeek 的按键。** 鼠标停在上面时，圆环背后会出现一个**圆形**高亮，提示"这里可以点"；同时**不会**弹出明细面板 —— 避免你以为要查看数据却误触重启。</sub>

![重启确认弹窗](docs/07-restart.png)

<sub>点下去会弹出确认框。点「是」后界面锁定为「重启进行中」，应用自动退出并重新打开 —— 改完插件代码不用再手动退出重开。</sub>

几个保护措施：

| 场景 | 行为 |
|---|---|
| 请求发出中 | 关闭按钮隐藏，不能关 |
| 任务已提交 | 界面锁定「重启进行中，请稍候……」 |
| 60 秒内重复点 | 拒绝，提示「上一次重启还在进行中」 |
| 60 秒内没重启成功 | 解除锁定，显示失败原因，可重试 |
| `launchctl` 提交失败 | 明确报错，不会卡在"正在重启" |

## 四、悬停数字：看今日明细

鼠标移到**数字**上，弹出面板：

![深色模式的明细弹层](docs/08-popover-dark.png)

<sub>**深色模式**：灰底面板，水平居中于侧边栏，浮在账户行上方。</sub>

![浅色模式的明细弹层](docs/09-popover-light.png)

<sub>**浅色模式**：同一个面板，白底深字。</sub>

面板里每一行是什么意思：

| 行 | 含义 |
|---|---|
| **今日** | 下面三行都只统计今天（本地时间 0 点起） |
| **高峰花费** | 今天在**高峰时段**花的钱 |
| **闲时花费** | 今天在**闲时时段**花的钱 |
| **合计** | 上面两项之和 = 今天总花费 |
| **Tokens** | 今天消耗的 token 总量（输入 + 输出 + 缓存） |
| **缓存命中** | 缓存命中率 = 命中 token ÷ 总 token |
| **请求数** | 今天发了多少次请求 |
| **⚡ 距高峰还有 12h 14m** | 距离下一次峰谷切换还有多久 |
| **用量/充值** | 点击跳转平台用量页面 |

> 💡 **这些数字是本地估算**：插件读本机会话日志，乘内置价目表算出来的。
> 而「余额」是平台接口的真实值。两者来源不同，所以**不会严格同步** —— 这是设计如此。

## 五、圆环的三种颜色

### 🟢 绿环 = 闲时（便宜）

现在是闲时，单价便宜。环心的电源图标也是灰绿色。

### 🟡 黄环（琥珀）= 高峰（贵）

高峰时段：**工作日 09:00–12:00、14:00–18:00**（北京时间）。

这段时间单价翻倍，环心和高峰段都会变成琥珀色 `#ffb020`，提醒你"现在用会贵"。

### 🔴 红环 = 余额不足 ¥3

余额低于 **¥3** 时：

- **环心图标变红** `#ff5c7a`
- **高峰段变红**
- **徽章外围出现红色呼吸光晕**（2 秒一次，一明一暗）

这是"快去充值"的警示。

### ⚠️ 一个容易误会的细节：圆环其实是**两段**

圆环不是整环一个颜色，而是按**今天的钱花在哪**切开的：

| 环上的部分 | 代表 |
|---|---|
| **琥珀色那段** | 今天在**高峰**花的钱（占比） |
| **灰绿色那段** | 今天在**闲时**花的钱（占比） |

所以：

- 整环几乎全绿 → 今天的钱基本都在闲时花的（省）
- 琥珀段很长 → 今天有相当比例是在高峰烧掉的（费）

**环心图标的颜色**才代表「**此刻**是高峰还是闲时」。

## 六、刷新

点一下**数字区域**，立即重新读取余额和今日花费。刷新时圆环上有一段缺口绕圈转动。

此外每 **60 秒**还有一次自动刷新。

## 七、浅色 / 深色自动适配

不需要手动设置。DSH 切换主题时，插件自动跟着变：

| 元素 | 深色 | 浅色 |
|---|---|---|
| 徽章文字 | 浅色字 | 深色字 |
| 明细弹层 | 灰底 `#34383F` | 白底 |
| 重启弹窗 | 灰底 `#34383F` | 白底 |
| 悬停高亮 | 白色 17% 叠加 | 深色 7% 叠加 |

原理：DSH 深色时 `<body>` 上有 `data-ds-dark-theme` 属性，插件据此切换。

## 安装

> ⚠️ **不要**把插件加进 `package.json` 的 `dsh.profile.bundles` —— 应用启动时会清空该项，插件会失效。请用下面的**补丁层**方式。

### 1. 克隆到插件目录

```bash
git clone https://github.com/Aya-zhang/dsh-quota-ring.git ~/.dsh/plugins/dsh-quota-ring
```

### 2. 在 profile 的 node_modules 里建立软链

```bash
ln -s ~/.dsh/plugins/dsh-quota-ring \
      ~/.dsh/profiles/desktop/node_modules/dsh-quota-ring
```

### 3. 在 profile 的补丁层注册

编辑 `~/.dsh/profiles/desktop/cordis.patch.yml`，在文件末尾追加：

```yaml
- insert:
    - id: quota-ring
      name: dsh-quota-ring
```

### 4. 重启 DSH

重启后左下角就会出现余额环。

## 数据来源与隐私

- **余额**：调用 DeepSeek 官方余额接口
- **今日花费**：读取本机 DSH 会话日志（`~/.dsh/`），按内置价目表计算
- **网络**：只访问 `api.deepseek.com` 与 `platform.deepseek.com`
- **凭据**：读取本机已保存的 API Key / User Token，**不发送给任何第三方**
- 不上报、不统计、不联网存储任何数据

---

## 已知限制

1. **依赖侧边栏类名** —— 为了把徽章移到账户名右侧，CSS 用了 `[class*="footArea"]` 这类选择器。DSH 更新后若改类名，徽章会退回「独占一行」（不会崩溃）。
2. **布局按 260px 侧边栏调校** —— 侧边栏宽度不同时，位置可能需要微调。
3. **价格表固定写在代码里** —— 官方调价后估算会不准，需手动更新 `lib/index.js` 的 `PRICING`。
4. **点圆环会重启应用** —— 破坏性操作，会中断当前会话。
5. **余额与今日不会严格同步** —— 余额是接口真实值（2 位小数），今日是本地估算（4 位小数），数据源不同。
